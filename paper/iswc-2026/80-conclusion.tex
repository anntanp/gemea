\section{Conclusion}
\label{sec:conclusion}

GEMEA provides the first SPARQL endpoint, Linked Data browser, and MCP agentic
access layer for the DDB corpus, making 26.8 million cultural heritage objects
available for KG-based research.
By bridging a SPARQL endpoint and an MCP interface over the same graph, GEMEA
puts structured cultural heritage knowledge where frontier NLP and LLM research
can actually use it.
